# 山东大学校史互动页内容审核稿

## 口径与边界

- 1901-2013 年内容以 `/home/sha-opt/文档/历史沿革.txt` 为最高优先级，页面中的摘编不使用模型知识补写。
- 2013 年后只加入山东大学官方来源确认的 2016、2017、2021、2022 四个节点。
- 页面标题、时期名称属于导览文案；具体年份、人物、机构、事件和评价均须来自上述资料。
- 本稿对应 `frontend/src/data/history.ts`。页面只读取审核后的结构化数据，不从 RAG 或后台档案动态生成校史。

## 已知来源差异

- 本地稿记载 1901 年周学熙任管理总办；山东大学当前官网页面记载为唐绍仪。本项目按已确认规则采用本地稿口径。
- 本地稿对 1912 年教育体制使用“国民政府”表述，当前官网改为“当时的政府”。本项目不静默改写本地稿，但页面摘编只呈现学制调整及停办结果。
- 本地稿以“七七事变”说明 1937 年抗战背景，当前官网使用“全民族抗战爆发”。页面采用不改变事件次序的概括表达。

## 谱系图关系

- 官立山东大学堂停办后，师生分别转入六所专门学校；六校于 1926 年合并为省立山东大学。
- 省立山东大学与私立青岛大学的校产用于筹备国立青岛大学，后改称国立山东大学。
- 华中建设大学部分师生并入临沂山东大学；相关办学力量后参与组建华东大学。
- 1951 年，青岛复校的山东大学与华东大学合校。
- 2000 年，原山东大学、原山东医科大学、原山东工业大学合并组建新的山东大学。
- 谱系图中的连线只表达上述沿革、汇流和办学空间拓展，不额外推断学术或组织传承关系。
